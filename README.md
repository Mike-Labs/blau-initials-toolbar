# simplr-initials-toolbar

## Overview
Display intials from a user fullname and set it as an avatar using custom font.

## Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- [Ionic CLI](https://ionicframework.com/docs/cli) (v6.2.1 or higher)

## Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Mike-Main/simplr-initials-toolbar.git
cd your-repo
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Project in the Browser
```bash
ionic serve
```

## Features
- Getting full name of a user and splitting it to have intials in ion-fab-button.
- Customizing ion-fab-button to hold initials.
- Using a custom imported font.
